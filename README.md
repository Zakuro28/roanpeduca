# Roan Peduca — portfolio

Live at https://roanpeduca.vercel.app

Executive assistance, operations and project support. The site shows three case studies, writing, design and teaching portfolios, skills, education and leadership roles, volunteer work and contact details.

## Run it

```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, Tailwind CSS, Motion and Lucide icons.
